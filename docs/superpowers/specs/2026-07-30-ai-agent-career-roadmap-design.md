# AI/Agent 求职学习路线设计

董涵宇以 2026 年秋季开始试投、冬季获得 AI/Agent 应用开发实习为近期目标。本科阶段以 LLM/Agent 应用工程为主线；进入研究生阶段后，再根据经历与机会选择 Agent 系统、大模型算法或 AI Infra。

- C++、数据结构、计算机体系结构和操作系统有课程基础。

- 没有后端或 Web 开发经验。
- 了解少量机器学习概念，尚未使用 PyTorch 完成训练实验。
- 每周可稳定投入至少 20 小时。
- 本地设备为 16GB 内存、RTX 4060 Laptop 8GB 显存，可运行量化 7B/8B 模型和小型 PyTorch 实验。

## 方向决策

近期主攻 LLM/Agent 应用工程，原因是其本科阶段进入概率、学习周期与现有基础的综合收益最高。大模型算法和 AI Infra 保留为研究生阶段候选方向。

近期目标岗位：

- AI 应用开发实习生
- LLM 应用开发实习生
- Agent 开发实习生
- RAG/知识库方向实习生
- AI 后端开发实习生

不把纯 Prompt Engineer、大模型预训练、强化学习算法和 CUDA/推理引擎核心开发作为近期主投方向。

## 16 周学习结构

1. 第 1-3 周：Python 与基本工程能力。
2. 第 4-6 周：HTTP、FastAPI、数据库、页面与 LLM 基础。
3. 第 7-10 周：RAG、混合检索、引用和评测。
4. 第 11-14 周：Tool Calling、Agent 工作流、容错与评测。
5. 第 15-16 周：部署、文档、演示、简历和面试。

学习采用螺旋方式：学习最小知识，立即实现小功能，通过错误发现缺口，再补知识并集成到项目。

## 核心项目

项目名称为 **CareerLens：AI 岗位研究与求职 Agent**。

系统导入个人简历、学习记录与招聘 JD，提取结构化字段，支持带来源引用的检索和岗位对比，并通过受控 Agent 工具生成能力差距分析和学习任务。

### 主要组件

- Streamlit 页面
- FastAPI 后端
- SQLite 起步，后期迁移 PostgreSQL + pgvector
- 文档解析与结构化提取
- BM25、向量检索、混合检索和 Reranker
- 模型服务抽象，支持云端 API 与本地模型
- 先手写确定性工作流，后期按需要引入 LangGraph
- pytest、评测集、日志、成本与失败分析
- Docker Compose 部署

### 安全与可信原则

- Agent 不直接访问数据库，只能调用经过参数校验的工具。
- 岗位与能力结论必须附带来源证据。
- 输出明确区分已掌握、证据不足、暂未掌握和无法判断。
- 不虚构简历经历，不自动海量投递，不绕过招聘网站限制。
- 敏感写操作需要用户确认。

## 成功标准

16 周结束时应达到：

- 能独立使用 Python、FastAPI、SQL 和 Git 开发小型服务。
- 能解释 Token、Embedding、Attention、Transformer、RAG 和 Agent 的基本原理。

- RAG 有 30-50 条评测集及检索策略对照实验。
- Agent 有任务成功率、耗时、Token、成本和失败原因统计。
- 能在 5 分钟内演示项目，并说明系统选择、限制和改进过程。
- 从第 7 周前后开始试投，并根据反馈持续更新简历与项目。
