# CareerLens Week 2 学习计划

## 当前状态

- 主题：结构化数据、JSON 与确定性 JD 解析
- 状态：已完成
- 预计总时长：约 18–20 小时
- 前置成果：Week 1 本地 JD 清洗 CLI 与 8 个自动化测试

## 本周目标

Week 1 解决了“文本是否整洁”；Week 2 解决“程序怎样明确表示岗位字段”。

```text
原始 JD 文本
→ clean_jd() 清洗文本
→ 确定性规则提取字段
→ Python 结构化对象
→ JSON 文件
```

完成后应当能够：

- 使用字典、列表和嵌套结构表达岗位数据。
- 区分 Python 对象与 JSON 文本。
- 使用 `json` 标准库读写 UTF-8 JSON。
- 使用类型标注和 `dataclass` 定义岗位数据模型。
- 用明确规则从固定格式 JD 提取标题、职责和技能。
- 验证必要字段，并为正常、边界和错误输入编写测试。
- 从 CLI 把脱敏 JD 转换为结构化 JSON。
- 说明确定性解析的能力边界，以及为什么后续仍可能需要 LLM。

## 本周项目边界

本周仍不引入：

- LLM API 或 Prompt。
- 数据库。
- FastAPI 或 Web 页面。
- RAG、Embedding 或 Agent。
- 为了“像正式项目”而提前增加复杂框架。

解析器只支持本周明确规定的练习格式，不声称能理解任意招聘 JD。

## 每日安排

### Day 1：字典、列表与嵌套数据

- 复习 `strip()`、`split()`、返回类型和变量命名。
- 使用嵌套字典与列表表达岗位、地点、要求、职责和技能。
- 学习安全读取、成员判断、修改、追加与遍历。
- 完成 `practice/week2/day1_job_record.py`。

### Day 2：JSON 基础

- 理解 Python 对象、JSON 文本和 JSON 文件的区别。
- 学习 `json.dumps()` / `loads()` 与 `dump()` / `load()`。
- 理解 `ensure_ascii=False`、缩进和 UTF-8。
- 完成岗位数据的 JSON 往返转换与文件保存。

### Day 3：类型标注与 `dataclass`

- 复习参数与返回类型合同。
- 学习 `list[str]`、`dict[str, ...]`、`str | None`。
- 理解普通字典拼写错误不易发现的问题。
- 定义 `JobPosting` 数据模型，并转换为字典。

### Day 4：确定性字段解析

- 设计固定练习格式和字段规则。
- 补齐 `responsibilities` 字段，保持模型与周交付目标一致。
- 区分标题行、工作方式、薪资、章节标题、编号职责和技能行。
- 将清洗文本解析为岗位数据模型。
- 保留明确限制，不使用正则或 LLM 掩盖基础逻辑。

### Day 5：验证、错误处理与 pytest

- 区分缺失字段、空字段和不支持格式。
- 使用清楚的 `ValueError` 或结果状态表达失败。
- 为解析器编写正常、边界和错误输入测试。
- 继续练习根据失败报告定位实际值与预期值。

### Day 6：CLI 整合与 JSON 输出

- 共同决定怎样扩展命令而不破坏 Week 1 行为。
- 读取原始 JD、清洗、解析并输出 UTF-8 JSON。
- 更新项目 README 的运行、格式和限制说明。
- 运行测试、检查隐私、创建语义清楚的提交并推送。

### Day 7：闭卷复现与周复盘

- 不看旧代码，复现简化版字段解析函数。
- 口述文本、Python 对象、数据模型和 JSON 之间的转换。
- 验收 Week 2 停止条件并保存周总结。

## Week 1 补强规则

每天在真实任务中继续检查：

- 字符串方法返回的是字符串还是列表。
- 函数标注与实际返回类型是否一致。
- 变量名是否反映类型、职责和处理状态。
- 当前是在 Shell、Python REPL 还是项目文件中写命令。
- 相对路径相对于哪个当前目录解析。
- 能否准确写出运行和测试命令。

## Week 2 停止条件

满足以下条件才进入 Week 3：

- 能独立构造和读取包含字典与列表的嵌套岗位数据。
- 能解释 `dump` / `dumps`、`load` / `loads` 的输入输出差别。
- 能从空白文件定义一个简单 `dataclass` 并实例化。
- 能解释解析器支持哪些格式、拒绝哪些格式。
- 能运行并解释解析器测试。
- 能从命令行生成一份 UTF-8 JSON 岗位文件。
- 核心字段解析逻辑不是由 AI 整段生成后直接粘贴。

若未满足，Week 3 开始前先安排 2–4 小时补强，不带着明显欠账进入下一阶段。
