## 今天会新增的项目内容

在真正创建前，先理解各自职责：

```text
careerlens/
├── .venv/                    # 本机隔离的 Python 环境，由工具生成，不是项目源码
├── requirements-dev.txt      # 记录测试等开发阶段依赖
└── tests/
    └── test_cleaner.py       # 只验证 cleaner.py 的行为
```

- `.venv/` 不应提交到 Git；Day 6 会通过 `.gitignore` 排除它。
- `requirements-dev.txt` 让其他人知道运行测试需要哪些第三方包。
- `tests/` 与 `src/` 分开，使“实现功能”和“检查功能”职责清楚。
- `test_cleaner.py` 不读写真实文件，只给清洗函数输入字符串并检查返回值。

## 阶段 3：虚拟环境与开发依赖（约 30 分钟）

先讲清命令的作用，再由学习者在项目根目录 `careerlens/` 逐条执行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install pytest
python -m pip freeze > requirements-dev.txt
```

学习点：

- [x] 虚拟环境为什么能隔离不同项目的第三方包。
- [x] `.venv` 是生成环境，不是自己编写的项目代码。
- [x] 激活后 `python` 和 `pip` 为什么指向 `.venv/`。
- [x] pytest 属于开发依赖，而清洗程序本身只使用标准库。
- [x] `pip freeze` 输出什么，`>` 为什么能把输出保存到文件。

可选参考资料：

- [Python 官方文档：venv](https://docs.python.org/zh-cn/3/library/venv.html)
- [pip 官方文档：pip freeze](https://pip.pypa.io/en/stable/cli/pip_freeze/)
