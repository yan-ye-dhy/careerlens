## 全程学习方法

- 学习最小必要知识，然后立即做小型实验和项目实践。
- 新增文件或代码前，先理解用途、位置、职责、输入输出和验证方式。
- 当前必须掌握的核心代码由学习者先尝试，模板和机械性内容可以由 AI 提案。
- AI 根据实际情况逐步增加帮助，优先引导定位错误，不默认给出完整答案。
- 每天按计划验收；未补齐明显欠缺时，不急着进入下一天。

## 16 周最终验收目标

- 能独立使用 Python、FastAPI、SQL 和 Git 开发小型服务。
- 能解释 Token、Embedding、Attention、Transformer、RAG 和 Agent 的基本原理。
- CareerLens 具有可复现代码、测试、评测、部署说明、脱敏 Demo 和演示视频。
- RAG 有 30–50 条评测集及检索策略对照实验。
- Agent 有任务成功率、耗时、Token、成本和失败原因统计。
- 能在 5 分钟内演示项目，并说明系统选择、限制与改进过程。
- 从第 7 周前后开始试投，根据反馈持续更新简历与项目。

## 进度维护规则

- 只在当天验收完成后，把对应学习日标记为“已完成”。
- 新的详细周计划应在该周开始前共同制定，并在本文档增加入口。
- 每个学习日创建独立的 `week-XX-day-XX.md`，当天学习过程只更新对应文档。
- 当天验收完成后，更新本文档的状态，但保留当日计划与完成记录。
- 每周复盘完成后，再统一清理该周的每日计划文档；清理前必须确认周总结和进度已经保存。
